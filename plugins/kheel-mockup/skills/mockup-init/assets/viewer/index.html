Serve this folder to view mockups

Browsers do not let a page opened from disk read the design system and mockup files, so the project space — the folder that holds design-system/ and the mockups — needs to be served over HTTP. In a terminal:

cd <the project space>
python3 -m http.server 8000

then open http://localhost:8000/design-system/.

If the page is already served and this message stays, the runtime failed to load — check that design-system/_runtime.js exists.
